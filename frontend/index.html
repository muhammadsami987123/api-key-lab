Three checks, one report. Same path your production code takes — nothing simulated.

3. Live completion

Questions people ask

Is my API key safe?

Your key lives in sessionStorage for this tab only and is cleared the moment you close it. It is relayed to the provider you picked through a stateless serverless function — no database, no logs, no analytics. Nothing is written to disk anywhere.

You can verify this yourself: open DevTools → Network while verifying.

Why is there a server proxy at all?

OpenAI, Mistral and a few others do not allow browser-origin requests (CORS). Without a proxy the browser cannot tell “invalid key” apart from “blocked by CORS”, which makes a validator useless. The proxy forwards one request and forgets it.

What does “insufficient quota” mean?

Your key is valid but the account has no credit or hit its spending limit. We surface the provider’s own message and the reset time so you know whether to top up or wait.

Can I test a local Ollama server?

Yes. Choose Ollama (local). Local calls run straight from your browser to localhost:11434 — they never touch our servers. Start Ollama with OLLAMA_ORIGINS=* if the browser blocks the request.

Which providers are supported?

OpenAI, Anthropic, Google Gemini, Groq, Mistral, OpenRouter, xAI, DeepSeek, Together, Perplexity, Ollama, any OpenAI-compatible endpoint, Azure OpenAI, AWS Bedrock and Google Vertex AI.
